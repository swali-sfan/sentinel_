# Sentinel IQ Document Formatter

Offline desktop tool. Ingests `.md`, `.txt`, `.docx`, `.pdf`, `.pptx`. Outputs
Sentinel-IQ-styled `.md` (with optional PDF render). No login. No cloud.

See [`INSTALL.md`](./INSTALL.md) for the install + run guide.

## Quick start

```bash
pip install -r requirements.txt
python -m src.app          # GUI
# or
python run_sample.py       # one-shot smoke test
```
